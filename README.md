## 📖 Overview
A distributed behavioral security mesh utilizing eBPF kernel probes and unsupervised isolation forests to detect lateral network movement, privilege escalation, and anomalous container process spawns with automated ingress quarantining.

This system was engineered as a capstone research project in **Cybersecurity & Cryptography**, featuring a modular 5-tier architecture, robust error boundaries, and verifiable benchmarks.

## 🚀 Key Features
- **Modular 5-Tier Architecture**: Clean separation between presentation, ingestion, core logic, persistence, and output channels.
- **Robust Error Handling**: Graceful degradation and resilient queue buffering for uninterrupted availability.
- **Academic Rigor**: Complete milestone roadmap, threat matrix, and oral defense revision materials.
- **Empirical Validation**: Automated performance metrics and verifiable benchmark suite.

## 🛠️ System Layers
1. **1. Decentralized Presentation Layer** (`Web3 / Client`) — Interactive DApp interface connecting cryptographic wallets and managing decentralized state signatures.
2. **2. Oracles & Off-Chain Middleware** (`Relayer / Middleware`) — Decentralized middleware providing off-chain computation, IPFS metadata storage, and oracle data feeds.
3. **3. Smart Contract Execution Layer** (`EVM / Smart Contracts`) — Deterministic, self-executing code deployed to the blockchain enforcing immutable domain rules and access controls.
4. **4. Distributed Ledger & Consensus** (`Consensus / Nodes`) — Decentralized peer-to-peer network verifying transactions through consensus algorithms and cryptographic blocks.
5. **5. Indexing & Subgraph Analytics** (`Indexing / GraphQL`) — High-speed event indexing and querying service mapping on-chain event logs into queryable GraphQL endpoints.

## 🚦 Getting Started

### Prerequisites
- Node.js (v18 or higher) or Python 3.10+ (depending on runtime)
- npm / yarn / pip

### Installation
```bash
git clone https://github.com/your-username/zero-trust-microsegmentation-and-behavioral-anomaly-engine-for-kubernetes-clusters.git
cd zero-trust-microsegmentation-and-behavioral-anomaly-engine-for-kubernetes-clusters
npm install
```

### Run Application
```bash
npm run dev
```
